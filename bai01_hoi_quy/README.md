# Bài 01 - Hồi quy tuyến tính

Thư mục bài thực hành môn Học máy ứng dụng.

## Cấu trúc

- `data/gia_nha.csv`: dữ liệu 60 căn hộ.
- `code/`: bảy chương trình mẫu của bài học.
- `baitap01/`: lời giải sáu bài tập phần 9.
- `figures/`: hình minh họa sinh ra khi chạy chương trình.
- `outputs/`: kết quả chạy.
- `scripts/`: tiện ích chạy lại bài.
- `Lab01.ipynb`: notebook Colab gốc.
