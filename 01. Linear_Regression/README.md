# Bài 01 — Hồi quy tuyến tính

Thực hành hồi quy tuyến tính trên dữ liệu giá nhà gồm 60 căn hộ.

## Cấu trúc

- `code/Lab1_LeQuyetTien.ipynb`: notebook các bước thực hành.
- `code/Baitap.ipynb`: lời giải sáu bài tập ở phần 9.
- `data/gia_nha.csv`: dữ liệu đầu vào.
- `figures/`: biểu đồ được sinh khi chạy bài tập.
- `outputs/`: kết quả dạng văn bản của hai notebook.
- `scripts/run_all.py`: chạy lại toàn bộ notebook.
- `requirements.txt`: các thư viện cần thiết.

## Chạy bài

```bash
python -m pip install -r requirements.txt
python scripts/run_all.py
```

Có thể mở từng notebook trong Google Colab hoặc Jupyter và chọn **Run all**. Khi tải dự án lên Colab, cần giữ nguyên các thư mục `code`, `data`, `figures`, `outputs` và `scripts`.
